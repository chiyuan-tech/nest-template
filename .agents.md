# Nest Template Agent Rules

## Purpose

This repository is a reusable website template for generated SaaS and AI-product sites. When Codex is launched inside a generated project, this file is the project-level rule entrypoint.

## Skill Source Rule

- Read this `.agents.md` first.
- Then read project-level skills from `.agents/skills/*/SKILL.md`.
- Do not read, copy, or fall back to user-level skills outside this project.
- If a required skill is missing from `.agents/skills`, stop and report the missing file instead of continuing with generic behavior.

- `.agents/skills/create-skill/SKILL.md`

- `.agents/skills/frontend-design/SKILL.md`
- `.agents/skills/high-end-visual-design/SKILL.md`

## Development Workflow

1. Read `.ai-task/brief.md`, `.ai-task/quality-prompt.md`, `.ai-task/template-skills-index.md`, and `.ai-task/skill-paths.json`.
2. Analyze the template structure, routes, metadata, JSON-LD, API routes, components, styles, media, and package scripts.
3. Use `.agents/skills/create-skill/SKILL.md` to create or update `.agents/skills/project-template/SKILL.md`.
4. Research the keyword and competitors. Competitor media is research-only and must not be published.
5. Use promptX Writer to author `.ai-task/seo-development-plan.md` and `.ai-task/seo-copy-map.md`.
6. Generate visual references after SEO copy exists, using `.agents/skills/imagegen-frontend-web/SKILL.md`.
7. Implement the landing page from visual references with `.agents/skills/image-to-code/SKILL.md` and `.agents/skills/cutting-pictures/SKILL.md`.
8. Implement `/how-to-use` and `/pricing` after the homepage.
9. Run visual QA, copy consistency checks, SEO audit, repair checklists, and second-pass checks.
10. Write final `.agents.md` updates only when they preserve this project-level skill-source rule.

## Landing Page Rules

- The visible landing page copy must come from `.ai-task/seo-copy-map.md` and `.ai-task/copy-lock-map.json`.
- Do not add, remove, shorten, expand, summarize, or rewrite public marketing copy for layout convenience.
- H1 and major H2s must preserve the immutable primary keyword from `.ai-task/brief.md`.
- SEO copy must not mention API, endpoint, SDK, request/response, webhook, token, key, provider endpoint, or model endpoint.
- The homepage must not add a standalone pricing SEO module. If a template skill requires a price component above FAQ, reuse the existing template component and record the placement.

## Visual And Media Rules

- Hero visual generation is mandatory.
- The generated Hero image is a design mockup, not a final pasted page section.
- Before coding Hero, analyze layers, identify text-free cutouts, and rebuild text, buttons, controls, cards, and UI labels as real HTML/CSS/components.
- Do not paste the full Hero reference image into the page body.
- Key Features must use generated images or assets that match each feature's exact copy meaning.
- All public images must show their complete important subject. Preserve aspect ratio and avoid cropped focal content unless the asset is explicitly decorative texture.
- Do not use CY placeholder media, template demo media, or competitor media in production paths.
- Generated or approved media must be recorded in `.ai-task/media/generated-asset-manifest.json`.

## Support Pages

- Add `/how-to-use` and `/pricing` links to both navigation and footer.
- Preserve the existing nav/header login interaction exactly. Do not change hrefs, onClick handlers, auth wiring, Clerk/OAuth wiring, routes, events, or component behavior.
- `/how-to-use` must be a media-led tutorial page, not a text-only article.
- Video products need an approximately 15-second local tutorial video under `public/media/generated/how-to-use/`.
- Image products need local tutorial images, before/after images, or image sequences.
- Audio products need local audio, waveform, or audio-step media.
- Tutorial media, captions, alt text, headings, and nearby copy must describe the same step and product outcome.
- If video generation is unavailable, competitor video may be collected only into `.ai-task/research/competitors/` for private frame/story-beat analysis, then replaced with original local or licensed tutorial media.
- `/pricing` must reuse the existing pricing component and behavior. Add only H1, description, metadata, and FAQ copy around it.

## QA Gates

- Create `.ai-task/skill-application-report.md` proving every required skill was read and applied.
- Create `.ai-task/copy-consistency-audit.md` and fix any mismatch against `.ai-task/copy-lock-map.json`.
- Create `.ai-task/visual-qa.md`, `.ai-task/visual-qa-repair-checklist.md`, and `.ai-task/visual-qa-second-pass.md`.
- Fail QA if the Hero uses the default narrow-left-copy/right-card screenshot layout, if important image subjects are cropped, if `/how-to-use` is text-only, if media and copy do not match, if template default theme colors remain, or if login behavior changed.
- Use `.agents/skills/seo-audit/SKILL.md` for the final SEO audit and write `.ai-task/seo-audit/SECOND-PASS-CHECK.md`.
