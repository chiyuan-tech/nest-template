This is a CY-composed SaaS homepage template. Read this file and project-level `.agents/skills/*/SKILL.md` files before work; do not fall back to user-level skills.

## Workflow

1. Read the brief, clone output, media manifests, skill index, and quality prompt.
2. Run `$clone-website` and Playwright research before page development, then use the findings for product-function, media and interaction evidence. Compose the actual homepage from the CY library and `cy_templeate.json`, rather than pixel-cloning the competitor.
3. Research the immutable keyword and competitor product functions online; write the sourced Sonnet input.
4. Implement the homepage only with real responsive components, local media, content slots, metadata, and JSON-LD.
5. Run the project Claude Sonnet writer runner after the content-slot map exists. Apply its locked copy exactly and reject competitor wording.
6. Run desktop/mobile QA, copy consistency/originality checks, and SEO audit repair cycles until the score is at least 95.

## Homepage Rules

- Reuse and display `Navbar`, `Footer`, and the existing pricing component. `Home` and `How to Use` link to homepage anchors; `Pricing` links to `/pricing`.
- Do not develop new support pages in this workflow.
- Use a clean modern sans-serif stack for body, headings, tables, navigation, and compatibility font classes. Instrument Serif, Fraunces, Georgia, Times New Roman, and generic serif fallbacks are forbidden unless the user explicitly requests an editorial serif design.
- Use real clone media in the mapped module or record a precise rejection reason. Do not reuse one source image/video across unrelated modules unless the competitor manifest proves the same asset is used in those exact sections. Video uses poster-first hover/focus playback and touch tap-to-toggle.
- Classify the researched product as video-first, image-first, audio-first, or mixed before mapping media into CY modules. Every saved media asset needs a mapped CY prop or a documented rejection reason. Video-first modules use `CyInlineMedia` video mode: local poster first, automatic muted viewport playback at 35% visibility, pause on exit, no manual-play dependency. Image-first modules lazy-load non-LCP images. Audio-first modules render the exact captured local source with accessible controls.
- CY components are available for reusable homepage modules. Read `.agents/skills/cy-register-module/SKILL.md`, register any new module in the CY registry, and keep its demo route and generator metadata in sync.

## Brand And SEO Rules

- Only user-uploaded `/logo.webp`, `/favicon.ico`, and `/share-img.png` may be used as final brand assets. Verify raster format and navigation/layout/metadata references. Keep `site-identity.generated.js` as the source for the exact keyword, initial brand name and TDK.
- The homepage copy map covers all visible text plus TDK, Open Graph/Twitter, JSON-LD, CTA, FAQ, captions, and alt text.
- Preserve the exact primary keyword in required SEO positions. No copied, translated, or near-verbatim competitor copy may remain.
- Treat every H1/H2/H3 as SEO copy, not a generic component label. Title and H1 must combine the exact keyword, the researched product/category phrase (for example `AI Video Generator`), and a concrete capability or benefit. Each H2 needs a topical category/entity plus distinct search intent; each H3 names a concrete capability, step, use case, objection, or outcome. Do not ship standalone headings such as Overview, Features, Why Choose, How It Works, Use Cases, Testimonials, Pricing, FAQ, Ready to Create, Get Started, or Learn More. Do not solve this by repeating the full primary keyword in every H2; keep complete-phrase occupancy density at or below 3%.
- Before completion, use Playwright to capture localhost and competitor at 1440px and 390px, compare every module and mapped media item, then inspect localhost HTML for title, description, keywords, canonical, OG/Twitter, favicon and JSON-LD parity.
