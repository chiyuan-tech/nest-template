# Nest Template Agent Rules

This is a clone-first homepage template. Read this file and project-level `.agents/skills/*/SKILL.md` files before work; do not fall back to user-level skills.

Required skills:

- `.agents/skills/create-skill/SKILL.md`
- `.agents/skills/clone-website/SKILL.md`
- `.agents/skills/design-taste-frontend/SKILL.md`
- `.agents/skills/frontend-design/SKILL.md`
- `.agents/skills/high-end-visual-design/SKILL.md`
- `.agents/skills/copywriting/SKILL.md`
- `.agents/skills/seo-audit/SKILL.md`

## Workflow

1. Read the brief, clone output, media manifests, skill index, and quality prompt.
2. Run `/clone-website` before page development, then use Playwright-captured and cloned assets as the visual and product-function reference.
3. Research the immutable keyword and competitor product functions online; write the sourced Sonnet input.
4. Implement the homepage only with real responsive components, local media, content slots, metadata, and JSON-LD.
5. Run the project Claude Sonnet writer runner after the content-slot map exists. Apply its locked copy exactly and reject competitor wording.
6. Run desktop/mobile QA, copy consistency/originality checks, and SEO audit repair cycles until the score is at least 95.

## Homepage Rules

- Reuse and display `Navbar`, `Footer`, and the existing pricing component. `Home` and `How to Use` link to homepage anchors; `Pricing` links to `/pricing`.
- Do not develop new support pages in this workflow.
- Use the clone's available local font files. If unavailable, use the named local Instrument Serif fallback; never rely on browser-default typography.
- Use real clone media in the mapped module or record a precise rejection reason. Video uses poster-first hover/focus playback and touch tap-to-toggle.
- Do not use CY components, template placeholders, or deprecated visual-conversion workflows.

## Brand And SEO Rules

- Only user-uploaded `/logo.webp`, `/favicon.ico`, and `/share-img.png` may be used as final brand assets. Verify raster format and layout/metadata references.
- The homepage copy map covers all visible text plus TDK, Open Graph/Twitter, JSON-LD, CTA, FAQ, captions, and alt text.
- Preserve the exact primary keyword in required SEO positions. No copied, translated, or near-verbatim competitor copy may remain.
